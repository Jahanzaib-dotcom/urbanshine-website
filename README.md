# Urban Shine — High-Performance Cleaning & Restoration Website

A bespoke, ultra-fast, high-converting website for **Urban Shine** (`urbanshinemelb.com.au`), engineered in clean vanilla HTML5, CSS3, and JavaScript, following the modern design system, layout, and precision UI patterns of **UrbanX** (`urbanxpestcontrol.com`).

---

## 🚀 Key Features

1. **Precision UI & Typography (UrbanX Design System)**:
   - Deep obsidian navy (`#060B12`, `#0B1320`), clean slate grays, electric cyan accents, and high-visibility status indicators.
   - Dual-font typography: `Space Grotesk` for high-impact geometric headers and `Inter` for legibility.
   - Micro-interactions, hover glow cards, status badges, and smooth scroll navigation.

2. **Complete 12-Service Directory**:
   - **Cleaning & Upholstery**: Carpet Steam Cleaning, Couch & Upholstery Restoration, On-Site Curtain Cleaning, Deep Mattress Sanitisation, Chemical-Free Steam Clean.
   - **Floor Care & Sanding**: Floor Refresh & High-Gloss Polish, 99% Dust-Free Floor Sanding, Complete Heritage Timber Restoration, Rotary Tile & Grout Deep Extraction.
   - **Outdoor & Maintenance**: Outdoor Timber Decking Restoration, Split System Aircon Sanitisation Flush (&lt;1 hour turnaround).
   - **24/7 Emergency Response**: Rapid Mobile Flood Water Extraction & Industrial Dehumidification.

3. **Proprietary Technology Showcase — Urban Shield™**:
   - Dedicated comparison matrix highlighting the 99.9% antibacterial barrier included **100% free** with all carpet and fabric cleans.

4. **Live Interactive Cost & Quote Estimator**:
   - Real-time calculator enabling users to select carpet rooms, couch sizes, AC units, and tile square meterage to generate transparent estimate ranges.
   - "Lock In Quote" button transfers customized estimates directly into the booking modal.

5. **Integrated Dispatch & Modals**:
   - **Service Detail Modal**: Dynamic modal loaded with equipment specs, turnaround times, and scope of work for all 12 services.
   - **Booking Request Modal**: Comprehensive quote request engine with residential/commercial selector, preferred dates, and suburb validation.
   - **Success Modal with WhatsApp Handoff**: Auto-generates a structured dispatch message to `+61 432 979 551`.
   - **Floating WhatsApp Widget**: Persistent bottom-right CTA with live dispatch ping.

6. **Trust, Quality & Local SEO**:
   - **The Urban Shine 14-Day Guarantee**: Dedicated guarantee certificate box highlighting free re-treatment.
   - **Feefo 4.7★ Rating Display**: Integrated customer reviews (190+ verified ratings).
   - **Perth Suburb Coverage Directory**: Optimized for Cottesloe, Peppermint Grove, Dalkeith, Claremont, East Fremantle, North Beach, and greater Perth.
   - **Structured Schema.org**: Fully compliant `HomeAndConstructionBusiness` JSON-LD schema with complete phone numbers, email, and service areas.

## 🌐 Opening the Website

Open `index.html` directly in any web browser, or launch via a simple local HTTP server:

```bash
# Option 1: Open directly in default browser (macOS)
open /Users/JahanzaibDev/urbanshine-website/index.html

# Option 2: Run with Python local server
cd /Users/JahanzaibDev/urbanshine-website && python3 -m http.server 8080
```
